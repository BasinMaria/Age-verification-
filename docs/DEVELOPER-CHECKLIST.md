Этот документ объединяет все чеклисты из [COMPLIANCE.md](../COMPLIANCE.md) в один удобный список, организованный по фазам разработки. Дубликаты удалены.

## Фаза 1: Подготовка проекта

### Конфигурация сборки
- [ ] Bundle ID / Application ID настроен
- [ ] Signing certificates и Provisioning Profiles настроены (iOS)
- [ ] Keystore настроен (Android)
- [ ] Minimum SDK: iOS 16+ / Android API 26+
- [ ] Target SDK: последняя стабильная версия
- [ ] Build variants настроены (Debug / Release / Staging)
- [ ] Версионирование (CFBundleShortVersionString / versionName) настроено

### Структура проекта
- [ ] Apple: Xcode project с правильными capabilities (Push Notifications, Associated Domains, etc.)
- [ ] Android: Gradle project с правильными permissions в AndroidManifest.xml
- [ ] Папки для локализации созданы (en.lproj, ru.lproj / values, values-ru)
- [ ] Схема навигации определена и соответствует потокам согласий

### Зависимости и SDK
- [ ] Все сторонние SDK задокументированы (название, версия, назначение, данные)
- [ ] SDK не собирают данные до получения согласия пользователя
- [ ] Нет запрещённых SDK (например, собирающие IMEI, MAC-адрес без обоснования)
- [ ] Privacy Manifest (iOS) включает все Required Reason APIs
- [ ] Зависимости закреплены по конкретным версиям (no floating versions)

## Фаза 2: Реализация

- [ ] При возрасте < 18: мягкий отказ, НЕ блокировка устройства

- [ ] Каждый поток: работает "Not now" / отказ без блокировки нерелевантных функций
- [ ] Все согласия записываются с timestamp, версией, IP

- [ ] Система Report/Block реализована → [docs/UGC-MODERATION.md](UGC-MODERATION.md)
- [ ] Предмодерация фото/контента включена

- [ ] Пользователь может заблокировать другого пользователя

- [ ] Модераторский интерфейс для обработки жалоб

### GeoIP блокировка
- [ ] Заблокированные страны определены → [docs/BLOCKED-COUNTRIES.md](BLOCKED-COUNTRIES.md)
- [ ] GeoIP проверка на сервере (не только на клиенте)
- [ ] Cloudflare WAF правила настроены
- [ ] Пользователю показывается понятное сообщение о недоступности
- [ ] VPN/Proxy обнаружение реализовано (базовый уровень)

### Хранение данных и шифрование
- [ ] Данные зашифрованы at rest и in transit → [docs/DATA-STORAGE.md](DATA-STORAGE.md)
- [ ] TLS 1.2+ для всех API вызовов
- [ ] Sensitive данные в iOS Keychain / Android EncryptedSharedPreferences
- [ ] Нет sensitive данных в логах, UserDefaults, plain-text файлах
- [ ] Retention policy определена и реализована
- [ ] Бэкапы зашифрованы

### Настройки приватности
- [ ] Профиль по умолчанию — приватный (Private by Default)
- [ ] Пользователь может изменить видимость профиля
- [ ] Пользователь может контролировать, кто видит его активность
- [ ] Настройки приватности доступны в Settings → Privacy

### Удаление аккаунта
- [ ] Кнопка "Delete Account" доступна в Settings
- [ ] Подтверждение перед удалением (двухшаговое)
- [ ] Все пользовательские данные удаляются в течение 30 дней
- [ ] Пользователю отправляется email-подтверждение удаления
- [ ] Apple: IAP подписки напоминание об отмене
- [ ] Данные удаляются из бэкапов в пределах retention policy
- [ ] Соответствует Apple App Store Review Guideline §5.1.1
- [ ] Соответствует Google Play Data Deletion Policy

## Фаза 3: Перед подачей в магазин

### 👨‍💻 Программист

#### Качество кода
- [ ] Нет использования private/undocumented API (iOS)
- [ ] Нет `eval()`, `document.write()` или подобных конструкций
- [ ] Нет hardcoded API ключей или секретов в коде
- [ ] Нет unused permissions в Info.plist / AndroidManifest.xml
- [ ] Нет краш-логов при стандартном использовании
- [ ] Memory leaks проверены (Instruments / LeakCanary)
- [ ] Все TODO/FIXME адресованы перед релизом

#### Privacy Manifest (Apple)
- [ ] PrivacyInfo.xcprivacy файл создан
- [ ] Все Required Reason APIs задекларированы с корректными причинами
- [ ] NSPrivacyTracking = NO (если нет трекинга после согласия)
- [ ] NSPrivacyTrackingDomains пуст или содержит только одобренные домены
- [ ] Все сторонние SDK имеют свои Privacy Manifests
- [ ] Privacy Nutrition Labels в App Store Connect заполнены корректно

#### Data Safety (Google)
- [ ] Data Safety форма в Google Play Console заполнена
- [ ] Все типы собираемых данных указаны
- [ ] Цели сбора данных указаны для каждого типа
- [ ] Указано, какие данные передаются третьим сторонам
- [ ] Data deletion policy URL указан
- [ ] Соответствие между Data Safety и Privacy Policy проверено

#### Export Compliance
- [ ] Использование шифрования задокументировано
- [ ] ECCN классификация определена (если применимо)
- [ ] ITSAppUsesNonExemptEncryption в Info.plist установлен корректно
- [ ] Encryption Registration (BIS) выполнена, если требуется

#### Тестовый аккаунт для ревьюера
- [ ] Demo-аккаунт создан (email + пароль)
- [ ] Аккаунт прошёл верификацию возраста

- [ ] Credentials указаны в App Store Connect / Google Play Console
- [ ] Инструкции для ревьюера написаны (Review Notes)

#### Ссылки
- [ ] Terms of Service — URL работает, контент актуален
- [ ] Privacy Policy — URL работает, контент актуален
- [ ] Support URL — работает, есть контактная форма/email
- [ ] Community Guidelines — URL работает (если применимо)
