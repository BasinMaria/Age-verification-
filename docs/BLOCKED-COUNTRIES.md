## Как работает блокировка — уровни

> ⚠️ **Писать свой код для геоблокировки НЕ нужно.** Блокировка на уровне инфраструктуры (Cloudflare).
> **Мы НЕ делаем своё окно блокировки** — Cloudflare покажет своё системное окно.

### Уровень 1: App Store / Google Play (скачивание)

| Что | Как |
|---|---|
| **Apple App Store** | В App Store Connect → Pricing and Availability → убрать заблокированные страны из списка |
| **Google Play** | В Play Console → Release → Countries → убрать заблокированные страны |
| **Результат** | Пользователь из заблокированной страны **НЕ видит приложение** в магазине |

> Это **первый уровень** — пользователь не может даже скачать приложение.

### Уровень 2: Cloudflare WAF (веб-сайт + API)

| Платформа | Как | Кто показывает экран |
|---|---|---|
| **Веб-сайт** | **Cloudflare WAF → Custom Rules** → `ip.geoip.country in {"GB" "AU" "BR" "CN" "KR" "MY" "RU" "BY" "TM"}` → **Block** | **Cloudflare** показывает своё системное окно блокировки |
| **API бэкенда** | Тот же Cloudflare защищает API → запросы из заблокированных стран не проходят | Cloudflare блокирует на уровне сети |

> **Это самый высокий уровень проверки.** Cloudflare блокирует ДО того как запрос дойдёт до нашего сервера. Мы **НЕ создаём своё окно** — Cloudflare показывает своё стандартное.

### Уровень 3: Backend API (мобильное приложение — дополнительная проверка)

| Что | Как |
|---|---|
| **Если** приложение уже установлено (скачано до блокировки или через VPN) | Backend читает заголовок `CF-IPCountry` и возвращает `{ allowed: false }` |
| **Экран в приложении** | Показать экран «Сервис недоступен» (см. ниже) |

> Это **дополнительная** защита на случай если пользователь каким-то образом обошёл уровни 1 и 2.

## ⚠️ Путешественники — GeoIP по текущему местоположению

> **Вопрос:** Если пользователь из Израиля приехал в Беларусь — он блокируется?
> **Ответ: ДА.** GeoIP определяет **текущее** местоположение по IP-адресу, а не гражданство.

| Ситуация | Результат | Почему |
|---|---|---|
| Пользователь из 🇮🇱 Израиля → в 🇮🇱 Израиле | ✅ Доступ | Израиль не в списке блокировки |
| Пользователь из 🇮🇱 Израиля → приехал в 🇧🇾 Беларусь | ⛔ Заблокирован | IP = белорусский → Cloudflare блокирует |
| Пользователь из 🇮🇱 Израиля → вернулся в 🇮🇱 Израиль | ✅ Доступ снова | IP = израильский → разблокирован |
| Пользователь из 🇧🇾 Беларуси → приехал в 🇩🇪 Германию | ✅ Доступ | IP = немецкий → не в списке блокировки |
| Пользователь из 🇧🇾 Беларуси → использует VPN (IP = 🇩🇪) | ✅ Доступ | VPN-IP = немецкий → GeoIP видит Германию |

### Правовое основание

| Аспект | Объяснение |
|---|---|
| **Почему блокируем путешественников** | Закон страны **где находится пользователь** применяется к его интернет-деятельности. Если пользователь в Беларуси — на него распространяется белорусское законодательство |
| **Мы обязаны?** | Мы обязаны предпринять «**разумные меры**» (reasonable measures) по GeoIP. Это стандартная практика (Netflix, Spotify, etc.) |
| **VPN** | Если пользователь использует VPN — это **его решение и ответственность**. GeoIP = «разумные меры», мы не обязаны ловить VPN |
| **Данные аккаунта** | Аккаунт и данные **НЕ удаляются** при временной блокировке. Когда пользователь вернётся в разрешённую страну — всё работает |

## Экран блокировки (мобильное приложение)

> Этот экран показывается **ТОЛЬКО** если приложение уже установлено и пользователь пытается его использовать из заблокированной страны. В нормальном сценарии пользователь вообще не видит этот экран — Cloudflare блокирует раньше.

| Язык | Текст | Ключ |
|---|---|---|
| 🇬🇧 EN | We're sorry, our service is not available in your current location. If you are traveling, the service will be available when you return to a supported region. | `country_blocked_screen` |
| 🇷🇺 RU | К сожалению, наш сервис недоступен в вашем текущем местоположении. Если вы путешествуете, сервис станет доступен, когда вы вернётесь в поддерживаемый регион. | `country_blocked_screen` |

> **Обратите внимание:** текст говорит «current location» (текущее местоположение), а НЕ «your country» (ваша страна) — потому что пользователь может быть путешественником.

## Почему блокировка — законно

- Закон страны применяется к платформе, если она **работает** в этой юрисдикции
- GeoIP-блокировка = «**разумные меры**» по выполнению закона (reasonable measures)
- Если пользователь зайдёт через VPN — его ответственность
- Стандартная практика (Netflix, Hulu, Spotify и др.)
- **Мы не обязаны** проверять гражданство — только текущий IP
