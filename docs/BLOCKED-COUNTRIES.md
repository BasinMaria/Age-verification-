## Как блокировать

> ⚠️ **Писать свой код для геоблокировки НЕ нужно.** Блокировка на уровне инфраструктуры.

| Платформа | Как блокируются | Что делать |
|---|---|---|
| **Веб-сайт** | **Cloudflare Firewall Rules** — `ip.geoip.country` | Правило: `ip.geoip.country in {"GB" "AU" "BR" "CN" "KR" "MY" "RU" "BY" "TM"}` → Block |
| **Мобильное приложение** | **Backend API** — сервер определяет страну по `CF-IPCountry` | `{ allowed: false }` → экран блокировки |

> **Cloudflare блокирует на самом высоком уровне** — ещё до того как пользователь увидит контент сайта. Для мобильного приложения — проверка при первом запуске через Backend API.

## Почему блокировка — законно

- Закон страны применяется только если платформа **работает** в этой юрисдикции
- Если пользователь зайдёт через VPN — его ответственность (GeoIP = «разумные меры»)
- Стандартная практика (Netflix, Hulu и др.)
