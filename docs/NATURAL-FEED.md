# 🍃 Natural Feed — Хронологическая лента (ТЗ)

> **Что это:** Лента постов в обратном хронологическом порядке — новые сверху, старые ниже. **Никакого профилирования, никакого AI, никакого скоринга.**
>
> **Зачем нужна:** DSA Art. 27 **ОБЯЗЫВАЕТ** предоставить альтернативу рекомендательной системе, которая **не основана на профилировании**. Natural Feed — это та самая альтернатива.
>
> **Когда реализовать:** MVP (v1.0) — одновременно со Smart Feed. Natural Feed **проще** Smart Feed (нет скоринга), но **по закону обязательна**.

## 1. Принцип работы

```
Один принцип:  ORDER BY created_at DESC

Нет AI.         Нет скоринга.      Нет весов (W1–W12).
Нет профилирования.   Нет embeddings.    Нет персонализации.
```

Natural Feed показывает **все доступные посты** в строгом порядке по дате публикации — **новые сверху**. Это аналог того, как работали ленты Facebook и Instagram **до 2016 года**, и как сейчас работает "Recent" вкладка в Twitter/X.

### Что определяет порядок

| Фактор | Влияет на порядок? |
|---|---|
| Дата публикации (`created_at`) | ✅ **Единственный фактор** |
| Интересы пользователя | ❌ Нет |
| Подписки / друзья | ❌ Нет (но контент от подписок ВИДИМ, если visibility = followers) |
| Популярность (лайки, комменты) | ❌ Нет |
| Dwell time | ❌ Нет |
| Тип контента | ❌ Нет |
| Язык | ❌ НЕ фильтруется (показываем ВСЕ языки) |
| Сообщества | ❌ Нет |

## 2. Что показываем и в каком порядке

### Порядок ленты — строго хронологический

```
┌──────────────────────────────────────────────────┐
│    [For You ⚡]    [Recent 🕐] ← АКТИВЕН         │
├──────────────────────────────────────────────────┤
│  📝 Пост от @anna         — 1 мин назад          │
│  📸 Фото от @yoga_master  — 3 мин назад          │
│  🏢 Бизнес от @spa_center — 5 мин назад          │
│  💬 Дискуссия от @mike    — 8 мин назад          │
│  📝 Пост от @sarah        — 12 мин назад         │
│  📸 Фото от @unknown_user — 15 мин назад         │
│  ...                                              │
│  📝 Пост от @old_post     — 3 дня назад          │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─│
│  🔚 «You're all caught up!»                      │
│      You've seen all recent posts.                │
│      [Switch to For You ⚡]                       │
└──────────────────────────────────────────────────┘
```

### Типы контента в Natural Feed

| Тип | Показывать? | Примечание |
|---|---|---|
| Обычные посты (текст, фото, видео) | ✅ Да | Основной контент |
| Бизнес-посты | ✅ Да | Наравне со всеми, БЕЗ Diversity Slots |
| Посты из сообществ | ✅ Да | Если пользователь — участник сообщества |
| Блог-посты | ✅ Да | Наравне со всеми |
| Дискуссии | ✅ Да | Наравне со всеми |
| Рекламные / спонсорские посты | ❌ Нет | У BestMe нет рекламы |

> **Ключевое отличие от Smart Feed:** В Natural Feed **нет Diversity Slots**. Бизнес-пост НЕ вставляется каждые 5 позиций. Всё строго по времени.

## 3. Источники контента

Natural Feed показывает посты из следующих источников:

| # | Источник | Условие видимости |
|---|---|---|
| 1 | **Публичные посты** (`visibility = 'public'`) | Все пользователи видят |
| 2 | **Посты от подписок** (`visibility = 'followers'`) | Только если текущий пользователь подписан на автора |
| 3 | **Посты из сообществ** (`visibility = 'community'`) | Только если текущий пользователь — участник сообщества |
| 4 | **Свои посты** | Всегда видны автору |

> **Чего Natural Feed НЕ показывает:** Посты от заблокированных пользователей, удалённые посты, посты не прошедшие модерацию — см. [Раздел 4](#4-фильтры-что-не-показываем).

## 4. Фильтры (что НЕ показываем)

Даже в хронологической ленте есть **фильтры безопасности**. Это **НЕ ранжирование** (порядок не меняется) — это **исключение контента**, который пользователь не должен видеть.

| # | Фильтр | Причина | Закон / Правило |
|---|---|---|---|
| 1 | Удалённые посты (`status = 'deleted'`) | Автор или модератор удалил | — |
| 2 | Посты на модерации (`ai_moderation_status = 'auto_removed'`) | AI-модерация убрала | DSA Art. 14 |
| 3 | Посты от заблокированных (`user_blocks`) | Пользователь заблокировал автора | Apple §1.2, DSA Art. 16 |
| 4 | Посты помеченные «Не интересно» (`not_interested`) | Пользователь нажал «Not interested» | DSA Art. 27 |
| 5 | Скрытые посты (`user_hidden_posts`) | Пользователь нажал «Hide this post» | DSA Art. 27 |
| 6 | Посты от restricted-аккаунтов (`author.status = 'restricted'`) | Аккаунт ограничен модерацией | DSA Art. 14 |
| 7 | Приватные посты, на автора которых не подписаны | Visibility = 'followers' + нет подписки | Логика приватности |

### Что НЕ фильтруется

| Параметр | Фильтруется? | Почему |
|---|---|---|
| Язык контента | ❌ Нет | Хронология показывает ВСЁ |
| Категория / тема | ❌ Нет | Нет профилирования |
| Популярность | ❌ Нет | Нет ранжирования |
| Тип контента (фото/текст/видео) | ❌ Нет | Нет Diversity Slots |

## 5. SQL-запрос

### Основной запрос Natural Feed

```sql
SELECT p.*,
       u.username AS author_username,
       u.avatar_url AS author_avatar,
       u.is_business AS author_is_business
FROM posts p
JOIN users u ON u.id = p.author_id
WHERE p.status = 'published'
  -- 1. Не удалённые модерацией
  AND p.ai_moderation_status != 'auto_removed'
  -- 2. Не от заблокированных пользователей
  AND p.author_id NOT IN (
    SELECT blocked_id FROM user_blocks WHERE user_id = :current_user
  )
  -- 3. Не скрытые пользователем
  AND p.id NOT IN (
    SELECT post_id FROM user_hidden_posts WHERE user_id = :current_user
  )
  -- 4. Не помеченные «не интересно»
  AND p.id NOT IN (
    SELECT post_id FROM user_not_interested WHERE user_id = :current_user
  )
  -- 5. Не от restricted-аккаунтов
  AND u.status != 'restricted'
  -- 6. Видимость
  AND (
    p.visibility = 'public'
    OR (p.visibility = 'followers' AND p.author_id IN (
      SELECT following_id FROM follows WHERE follower_id = :current_user
    ))
    OR (p.visibility = 'community' AND p.community_id IN (
      SELECT community_id FROM community_members WHERE user_id = :current_user
    ))
    OR p.author_id = :current_user
  )
ORDER BY p.created_at DESC
LIMIT :page_size
OFFSET :offset;
```

### Индексы для производительности

```sql
-- Основной индекс для Natural Feed (хронология)
CREATE INDEX idx_posts_natural_feed
  ON posts (created_at DESC)
  WHERE status = 'published' AND ai_moderation_status != 'auto_removed';

-- Индекс для фильтра блокировок
CREATE INDEX idx_user_blocks_user ON user_blocks (user_id, blocked_id);

-- Индекс для скрытых постов
CREATE INDEX idx_user_hidden_posts ON user_hidden_posts (user_id, post_id);

-- Индекс для «не интересно»
CREATE INDEX idx_user_not_interested ON user_not_interested (user_id, post_id);
```

## 6. Пагинация и подгрузка

### Стратегия пагинации

| Параметр | Значение |
|---|---|
| **Размер страницы** | 20 постов (по умолчанию) |
| **Максимум на страницу** | 50 постов |
| **Тип пагинации** | Cursor-based (предпочтительно) или offset-based |
| **Подгрузка** | Infinite scroll — при достижении конца списка загружается следующая страница |

### Cursor-based пагинация (рекомендуется)

```
GET /api/feed?mode=natural&page_size=20
→ ответ включает "next_cursor": "2026-03-30T10:15:00Z"

GET /api/feed?mode=natural&page_size=20&cursor=2026-03-30T10:15:00Z
→ посты с created_at < cursor
```

**Почему cursor лучше offset:** При offset-пагинации если появился новый пост пока пользователь скроллит, посты сдвигаются и один пост может показаться дважды или быть пропущен. Cursor (по `created_at`) стабилен.

### SQL с cursor

```sql
SELECT p.*, u.username, u.avatar_url, u.is_business
FROM posts p
JOIN users u ON u.id = p.author_id
WHERE p.status = 'published'
  AND p.created_at < :cursor  -- вместо OFFSET
  AND ... (все фильтры из Раздела 5)
ORDER BY p.created_at DESC
LIMIT :page_size + 1;  -- +1 чтобы проверить has_more
```

> Если вернулось `page_size + 1` записей → `has_more = true`, отдаём `page_size` записей. `next_cursor = last_post.created_at`.

## 7. Когда контент заканчивается

### Проблема

Пользователь долистал до конца ленты — все посты показаны. Что делать?

### Решение: 3 уровня

```
Пользователь скроллит вниз
        │
        ▼
   [Есть ещё посты?] ── Да → Подгрузить следующую страницу
        │
       Нет
        │
        ▼
   Уровень 1: Показать карточку «You're all caught up!»
        │
        ▼
   Уровень 2: Предложить действие
        │
        ▼
   Уровень 3: Показать популярное (опционально)
```

### Уровень 1 — Карточка «Всё просмотрено»

| Элемент | Текст (EN) | Текст (RU) | Ключ перевода |
|---|---|---|---|
| **Иконка** | ✅ | ✅ | — |
| **Заголовок** | You're all caught up! | Вы всё просмотрели! | `feed_end_title` |
| **Подзаголовок** | You've seen all recent posts from the past 3 days. | Вы видели все посты за последние 3 дня. | `feed_end_subtitle` |

### Уровень 2 — Предложение действия

После карточки «всё просмотрено» показываем **одну** из кнопок:

| # | Кнопка | Текст (EN) | Ключ перевода | Действие |
|---|---|---|---|---|
| 1 | **Переключить ленту** | Switch to For You ⚡ | `feed_end_switch_smart` | Переключить на Smart Feed |
| 2 | **Подписаться** | Discover new accounts | `feed_end_discover` | Открыть Explore / Discovery |
| 3 | **Сообщества** | Join a community | `feed_end_join_community` | Открыть список сообществ |

> **Правило:** Если у пользователя < 10 подписок → показать «Discover new accounts». Если ≥ 10 → «Switch to For You ⚡».

### Уровень 3 — Показать «старое» (опционально, v1.5)

Если пользователь продолжает скроллить дальше карточки:

| Что показать | Описание | Отступ |
|---|---|---|
| **Посты старше 3 дней** | Продолжить хронологическую ленту дальше в прошлое | `created_at < 3_days_ago` |
| **Лимит** | Максимум до 14 дней назад | Дальше — пустая лента |

### Когда лента СОВСЕМ пустая (нет постов вообще)

Это происходит у **новых пользователей** без подписок в начале жизни платформы.

| Элемент | Текст (EN) | Текст (RU) | Ключ перевода |
|---|---|---|---|
| **Иллюстрация** | (пустая лента — дизайнер рисует) | — | — |
| **Заголовок** | Your feed is empty | Ваша лента пуста | `feed_empty_title` |
| **Подзаголовок** | Follow accounts and join communities to see posts here. | Подпишитесь на аккаунты и вступите в сообщества, чтобы видеть посты здесь. | `feed_empty_subtitle` |
| **Кнопка 1** | Discover accounts | Найти аккаунты | `feed_empty_discover` |
| **Кнопка 2** | Browse communities | Просмотреть сообщества | `feed_empty_communities` |

```

  "mode": "natural",
  "page_size": 20,
  "has_more": true,
  "next_cursor": "2026-03-29T14:20:00Z",
  "end_of_feed": false,
  "posts": [
    {
      "id": "uuid-1",
      "type": "photo",
      "author": {
        "id": "uuid-author",
        "username": "anna",
        "avatar_url": "...",
        "is_business": false
      },
      "content": "Morning yoga session 🧘",
      "media": [...],
      "created_at": "2026-03-30T10:30:00Z",
      "engagement": { "likes": 12, "comments": 3, "saves": 1 },
      "community": null
    },
    ...
  ]
}
```

### Когда `end_of_feed = true`

```json
{
  "mode": "natural",
  "page_size": 20,
  "has_more": false,
  "next_cursor": null,
  "end_of_feed": true,
  "end_of_feed_reason": "all_seen_3_days",
  "posts": [ ... последние посты ... ]
}
```

| `end_of_feed_reason` | Описание |
|---|---|
| `all_seen_3_days` | Все посты за 3 дня просмотрены |
| `no_content` | Нет контента вообще (пустая лента) |
| `max_history_reached` | Дошли до лимита 14 дней |

## 9. Разница с Smart Feed — сводная таблица

| Аспект | Smart Feed 🤖 | Natural Feed 🍃 |
|---|---|---|
| **Порядок** | По Score (формула W1–W12) | По `created_at DESC` (время) |
| **Профилирование** | ✅ Да (интересы, поведение) | ❌ Полностью отключено |
| **Персонализация** | ✅ Да | ❌ Нет |
| **AI / ML (в v2.0)** | ✅ Embeddings, cosine similarity | ❌ Никогда |
| **Diversity Slots** | ✅ Бизнес каждый 5-й, макс 3 подряд | ❌ Нет — всё по хронологии |
| **Cold Start** | ✅ 4 фазы разогрева | ❌ Не нужен — показываем всё |
| **Фильтры безопасности** | ✅ Заблокированные, удалённые, скрытые | ✅ Те же самые фильтры |
| **Кнопка «Не интересно»** | ✅ Влияет на Score + фильтр | ✅ Только фильтр (скрывает пост) |
| **Кнопка «Скрыть пост»** | ✅ Скрывает + влияет на Score | ✅ Скрывает (без Score) |
| **Язык** | Фильтруется по настройкам | ❌ НЕ фильтруется |
| **Закон** | DSA Art. 27 — основная лента | DSA Art. 27 — **обязательная** альтернатива |
| **Endpoint** | `GET /api/feed?mode=smart` | `GET /api/feed?mode=natural` |
| **Когда кончаются посты** | Маловероятно (Wide Reach) | Реально — см. [Раздел 7](#7-когда-контент-заканчивается) |

## 10. Юридический статус

### Почему Natural Feed обязательна

| Закон | Статья | Требование |
|---|---|---|
| **DSA** | Art. 27 | Платформы с рекомендательными системами **ОБЯЗАНЫ** предоставить хотя бы **одну альтернативу**, не основанную на профилировании |
| **EU AI Act** | Art. 50 | Пользователь должен знать, когда контент ранжируется AI. Natural Feed = режим **без AI** |
| **GDPR** | Art. 22 | Право не подчиняться автоматизированным решениям. Natural Feed = полное отключение автоматизации |

### Что Natural Feed юридически гарантирует пользователю

| Гарантия | Описание |
|---|---|
| **Нет профилирования** | Ничто в поведении пользователя не влияет на порядок постов |
| **Нет «пузыря»** | Пользователь видит ВСЕ доступные посты, а не подобранные алгоритмом |
| **Предсказуемость** | Пользователь точно знает принцип: новое сверху, старое ниже |
| **Прозрачность** | Не нужен раздел «почему мне показали этот пост» — потому что ответ один: «он новый» |

### Что НЕЛЬЗЯ делать в Natural Feed

| ❌ Запрещено | Почему |
|---|---|
| Вставлять «рекомендуемые» посты | Это профилирование |
| Поднимать популярные посты | Это ранжирование |
| Фильтровать по интересам | Это персонализация |
| Скрывать непопулярные | Это дискриминация контента |
| Показывать рекламу между постами | У BestMe нет рекламы (но даже если бы была — это нарушило бы «не-профилирование» принцип) |
